# ТестЛаб

Локальное веб-приложение для совместной ручной проверки проектов. Пользователи создают группы, добавляют участников по почте, описывают проверки и сохраняют результаты. В интерфейсе три раздела: **Обзор**, **Проверки**, **Участники**.

## Быстрый запуск

Проверено на Python 3.13. Для приложения нужен Python с модулем `bcrypt`; Node.js требуется только для JS-тестов и автоматической съёмки экранов.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python server.py
```

Открыть **http://127.0.0.1:8765**. Сервер работает, пока открыт этот процесс. Остановка — `Ctrl+C`. После изменения `server.py` сервер нужно перезапустить.

При первом запуске создаются файл базы `testlab.sqlite3`, демонстрационный администратор и «Общая группа»:

- Почта: `admin@testlab.local`
- Пароль: `Admin12345!`

Обычный пользователь регистрируется через интерфейс. **Каждый аккаунт может создавать группы. Любой участник группы может добавлять в неё зарегистрированных людей, создавать проверки и сохранять результаты.** Создание группы не повышает роль аккаунта. Даже администратор не получает доступ к группе без участия в ней.

## Возможности

- Проверка: название, шаги и ожидаемый результат.
- Результаты: «Не проверено», «Успешно», «Ошибка», «Заблокировано»; необязательный комментарий.
- Поиск по названию, фильтр результата и сортировка проверок; сортировка участников.
- Обзор: счётчики и круговая диаграмма текущих результатов.
- Совместная работа: видимые вкладки обновляются примерно каждые три секунды. Для разных аккаунтов используйте разные профили браузера либо обычное и приватное окно.

## Стек и файлы

- Сервер: Python и стандартный `http.server`.
- База: SQLite; структура описана в [schema.sql](schema.sql).
- Интерфейс: HTML, CSS, JavaScript без сборки и внешних библиотек.
- Хеширование паролей: `bcrypt`.

[server.py](server.py) обслуживает страницу и API; [app.js](app.js) строит интерфейс; [style.css](style.css) задаёт оформление.

## Проверка

```bash
python -m unittest -v test_workflow.py
node --check app.js
node test_ui.js
```

Тесты используют временные базы. Рабочие аккаунты и результаты не изменяются. Существующая база, резервные копии и локальные настройки исключены из Git; после клонирования новая база создаётся автоматически.
