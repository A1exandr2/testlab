# Архитектура

Браузер отправляет HTTP-запросы серверу. `server.py` открывает порт и запускает обработчик из `testlab/web.py`. Обработчик передаёт действия функциям `security.py` и `service.py`. Соединение с SQLite создаётся в `database.py`.

## Серверные модули

```text
testlab/
  config.py       пути и общие значения
  database.py     подключение и начало работы с базой
  migrations.py   перенос данных предыдущей версии
  security.py     регистрация, вход, сеансы
  service.py      группы, проверки и результаты
  validation.py   проверка полей формы
  web.py          HTTP и маршруты
```

`web.py` отвечает только за протокол, файлы и выбор действия. Словарь ACTIONS связывает адреса с функциями. `service.py` содержит отдельные понятные функции: create_project, invite_member, create_check, save_result и get_state. Проверка текста и идентификаторов вынесена в validation.py.

Перенос прежних данных отделён от рабочих операций в migrations.py. Он выполняется один раз по отметкам app_settings. Существующие базы и правила прав сохранены.

## Интерфейс

Файлы находятся в static. HTML подключает пять обычных скриптов с defer в порядке state, api, views, forms, app. Они используют общие переменные и функции, поэтому сборщик не нужен. views.js содержит поиск, сортировку, списки и диаграмму; forms.js - вход и формы; app.js - обработчики и опрос сервера.

CSS разделён на общие правила, расположение блоков, компоненты и адаптацию. Последовательность правил сохранена. Сервер отдаёт только заранее найденные файлы каталога static по /static/ и начальную страницу по /. База, SQL и исходники Python не публикуются.

## Данные и права

Группу создаёт любой вошедший пользователь. Любой участник добавляет коллег, проверки и результаты. Администратор также должен состоять в группе. Роль аккаунта не повышается при создании группы, а метка project_members.role не даёт обхода проверки участия.

Пароли хранятся как bcrypt-хеши. Cookie содержит случайный токен, в sessions хранится его SHA-256. Сеанс действует 12 часов. POST после входа проверяет CSRF и переданный Origin. Пять неверных входов по почте ограничивают новые попытки на пять минут.

Каждый результат добавляет runs. Запрос выбирает максимальный id для каждой проверки. Предыдущие результаты остаются в базе. Интерфейс обновляет состояние примерно раз в три секунды, не заменяет открытую форму и не принимает устаревший ответ после смены группы или выхода.
