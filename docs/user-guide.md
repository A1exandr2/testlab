# Работа в приложении

## Войти или зарегистрироваться

Откройте адрес приложения. Для существующего аккаунта заполните почту и пароль и нажмите **Войти**. Для нового нажмите **Создать аккаунт**, укажите имя, почту и пароль от 10 символов, затем **Зарегистрироваться**. Вход произойдёт автоматически.

Если групп нет, нажмите **+ Новая группа** или передайте почту любому участнику существующей группы, чтобы он добавил вас. Обычный аккаунт может создавать группы и добавлять людей наравне с демонстрационным администратором.

## Группы и люди

**+ Новая группа** → название → **Создать группу**. Новая группа выбирается автоматически. Переключатель **Группа** показывает только группы текущего аккаунта.

**Участники** → **+ Добавить участника** → почта зарегистрированного пользователя → **Добавить участника**. Добавлять может любой участник группы. В таблице видны имя, почта, тип аккаунта и время добавления; список сортируется по имени или дате.

## Проверки

В «Обзоре» или «Проверках» нажмите **+ Добавить проверку**. Заполните название, шаги и ожидаемый результат. После сохранения статус — **Не проверено**.

В списке нажмите **Открыть**, выполните шаги в проверяемом проекте, выберите результат и при необходимости заполните комментарий. **Сохранить результат** записывает изменение для всей группы.

| Результат | Значение |
| --- | --- |
| Не проверено | Ещё не выполняли либо сбросили результат. |
| Успешно | Ожидаемый результат получен. |
| Ошибка | Результат отличается от ожидаемого. |
| Заблокировано | Выполнению мешают внешние условия. |

**Закрыть**, **Отмена**, `Esc` и щелчок по затемнённой области отменяют несохранённые изменения формы. Во время сохранения элементы временно отключены.

## Найти нужные записи

В «Проверках» введите часть названия. Поиск не учитывает регистр. Выберите результат в фильтре и порядок в сортировке: новые/старые, название А–Я/Я–А, сначала ошибки. Последний вариант располагает статусы так: ошибка, заблокировано, не проверено, успешно; внутри статуса сначала новые.

Поиск, фильтр и сортировка работают совместно. Для полного списка очистите строку поиска и выберите **Все результаты**. Надпись **Показано X из Y** показывает число отобранных записей.

## Сводка и совместная работа

«Обзор» показывает количество проверок по текущим статусам. Нажатие карточки открывает отфильтрованный список. Диаграмма отражает все текущие результаты, процент в центре — долю успешных проверок.

Для двух аккаунтов используйте отдельные профили или обычное и приватное окно. Изменения видны примерно через три секунды в видимой вкладке. Незавершённая форма при опросе не перерисовывается. Последний сохранённый результат одной проверки становится текущим.

**Выйти** завершает текущую сессию профиля. Для продолжения потребуется повторный вход.

## Что делать при ошибке

| Ситуация | Действие |
| --- | --- |
| Неверная почта или пароль | Проверить данные и раскладку. |
| Слишком много входов | Подождать пять минут. |
| Человек ещё не зарегистрирован | Дождаться регистрации перед добавлением. |
| Человек уже в группе | Найти его в таблице, повторно не добавлять. |
| Нет связи | Проверить адрес и работу сервера. Если сообщили, что данные уже сохранены, не создавать запись повторно. |
| Сессия изменилась | Обновить страницу и повторно войти. |

Расширенное руководство с 14 снимками экрана собирается по [инструкции](user-guide/README.md).
