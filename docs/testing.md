# Проверка проекта

Из корня проекта с установленным bcrypt:

```bash
python -m unittest discover -s tests -v
node tests/test_ui.js
```

Восемь тестов tests/test_workflow.py сохранены при переносе кода: они проверяют совместную работу, изоляцию групп, регистрацию без повышения роли, валидацию, ограничение входа, повторную инициализацию и перенос прежних данных. Менялись импорты модулей, а не ожидаемые результаты.

Пять tests/test_http.py дополнительно поднимают настоящий HTTP-сервер на свободном локальном порту. Проверяются загрузка всех 10 ресурсов из HTML, MIME и заголовки, запрет доступа к исходникам и базе, неправильный JSON, отдельные сеансы двух участников, выход, CSRF, Origin, истечение сеанса и откат транзакции при ошибке добавления участника. Все базы временные.

tests/test_ui.js загружает реальные пять файлов JavaScript в порядке из HTML. Проверяет поиск, сортировку, фильтр, диаграмму, экранирование текста, права и пустую выдачу. Полный набор Python содержит 13 тестов.

Для проверки интерфейса в Chrome без сборки руководства:

```bash
TESTLAB_CAPTURE_ONLY=1 node tools/capture_guide.js
```

Инструмент использует отдельные временные базу и профиль, проходит вход, регистрацию, создание группы, добавление участника, разделы, фильтр и формы; сохраняет 14 снимков. Обычный запуск без TESTLAB_CAPTURE_ONLY также собирает PDF и требует зависимости из requirements-docs.txt. Рабочая база при проверке не меняется.

Синтаксис всех скриптов можно проверить через node --check для каждого файла static/js. Изменения Python требуют перезапуска сервера. Нагрузочные испытания большого числа пользователей не проводились.
