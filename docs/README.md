# Документация ТестЛаб

Документация описывает реализацию проекта на 28.10.2026. Основные действия одинаковы для обычного аккаунта и демонстрационного администратора: создание групп, добавление участников, создание проверок и сохранение результатов. Доступ к данным ограничен членством в группе.

## Как читать

1. [setup.md](setup.md) — запустить приложение на новом компьютере.
2. [user-guide.md](user-guide.md) — пройти рабочий сценарий через интерфейс.
3. [architecture.md](architecture.md) — понять устройство и поток запросов.
4. [database.md](database.md) — разобраться в данных и связях.
5. [api.md](api.md) — работать с HTTP API.
6. [testing.md](testing.md) — проверить изменения.
7. [maintenance.md](maintenance.md) — сохранить базу и передать проект.
8. [user-guide/README.md](user-guide/README.md) — снять экраны и собрать PDF-руководство.

## Карта исходников

```text
testlab/
├── server.py                 # HTTP-сервер, авторизация, API, подготовка базы
├── schema.sql                # Таблицы и индексы SQLite
├── index.html                # HTML-оболочка страницы
├── app.js                    # Экраны, формы, запросы, синхронизация
├── style.css                 # Оформление и адаптация под ширину экрана
├── favicon.svg               # Значок вкладки
├── requirements.txt          # Зависимость для запуска приложения
├── requirements-docs.txt     # Дополнительные зависимости генератора PDF
├── test_workflow.py          # Проверки API с независимыми сессиями
├── test_ui.js                # Проверки функций интерфейса в Node.js
├── tools/
│   ├── capture_guide.js      # Съёмка 14 экранов в отдельной демонстрационной базе
│   ├── build_guide.py        # Сборка PDF и Markdown
│   └── guide_source.md       # Исходный текст формального руководства
└── docs/                     # Техническая и пользовательская документация
```

При запуске рядом с исходниками появляется `testlab.sqlite3`. Это рабочие данные, а не часть поставляемого исходного кода. Файлы базы, её служебные файлы, резервные копии, виртуальное окружение и локальные файлы авторизации не включаются в репозиторий.
