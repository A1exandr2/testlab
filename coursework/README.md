# Материалы курсового проекта ТестЛаб

- `Курсовой проект ТестЛаб.docx` — единая пояснительная записка, 36 страниц; 25 страниц до списка литературы, включая титульник.
- `testlab_demo.sqlite3` — отдельная демонстрационная база из 7 таблиц, в каждой от 1 до 7 записей.
- `demo.sql` - SQL заполнения после выполнения `sql/schema.sql` и `testlab.database.init_db()`.
- `tools/create_demo.py` — создание новой учебной базы и проверка количества записей, внешних ключей и структуры.

На титульном листе требуется заполнить курс, группу и ФИО. Подписи проставляются при сдаче.

Рабочее приложение запущено на http://127.0.0.1:8765. Вход: `admin@testlab.local`, пароль `Admin12345!`.

Для отдельного просмотра уже подготовленной учебной базы из корня проекта:

```bash
TESTLAB_DB=coursework/testlab_demo.sqlite3 /tmp/testlab-course-venv/bin/python server.py --port 8766
```

Учебный вход на http://127.0.0.1:8766: `anna@example.test` или `ivan@example.test`, пароль обоих аккаунтов `Demo12345!`.

Временное окружение `/tmp/testlab-course-venv` создано при подготовке. Для постоянного окружения следует выполнить инструкции корневого README.md. Повторное заполнение существующей учебной базы не требуется: tools/create_demo.py специально останавливается при наличии файла.

Проверки: пройдены 13 тестов Python, включая реальный HTTP-сервер, проверки JavaScript и сценарий Chrome с 14 экранами. Рабочие данные при тестировании не изменялись. Команды находятся в корневом README.md и docs/testing.md. Отчёт обновлён под модули testlab, каталоги static и sql, а также инструмент tools/create_demo.py.
